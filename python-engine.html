C2PA://strip

This UI doesn't reimplement your script — it runs your actual convert_image.py inside a WebAssembly Python runtime (Pyodide) directly in this page. strip_c2pa_jpeg() and strip_by_resave() execute unmodified.

How the integration works: on load, Pyodide + Pillow download into this page (~20 MB, once). Your uploaded file is written into Pyodide's in-memory filesystem, then your file's own strip_c2pa_jpeg(in_path, out_path) / strip_by_resave(in_path, out_path) functions are called on it exactly as written — no server involved. The one addition is scan_segments(), a small read-only helper for the map below, since your file's detect() depends on the native c2pa-python library, which has no WebAssembly build and can't load in-browser.

Prefer something instant with no download? Use the lightweight JS version instead.

Note: C2PA is a voluntary transparency signal for content provenance. Some jurisdictions (e.g. the EU AI Act) place disclosure obligations on AI-generated media, and removing this marker to represent synthetic content as human-made may conflict with those rules or a platform's terms. Use this on your own files and for legitimate reasons — e.g. privacy, or clearing metadata before sharing a personal photo.
